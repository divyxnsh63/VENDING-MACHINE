Vending Machine

About
A simple Python vending machine project that lets users view products, buy items, pay money, get change, and update item details.

Features
- View items, prices, and stock
- Buy items and calculate change
- Automatically update stock
- Edit item name, price, and stock

Requirements
- Python 3
- VS Code or any Python editor
- No external libraries required

How to Run

1. Open the project folder in VS Code.
2. Open Terminal.
3. Run:

python3 vendingg.py

On Windows:

python vendingg.py

4. Follow the menu shown on the screen.

Python Concepts Used
Dictionaries, lists, functions, loops, conditions, user input, and basic error handling.

Conclusion
This project is a simple example of using Python to solve a real-life vending machine problem.
