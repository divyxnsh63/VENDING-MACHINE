# Vending Machine Project

## About the Project

This is a simple vending machine program made using Python.

The program has two users:

- Customer
- Admin

Customers can view items, search for an item and buy an item.

The admin can manage items, stock and check sales information.

## Features

### Customer

- View available items
- Search for an item
- Buy an item
- Calculate change
- Exit the vending machine

### Admin

- Admin login
- View items
- Add a new item
- Edit an item
- Remove an item
- Add stock
- Search for an item
- View sales report
- View low-stock items
- Logout
